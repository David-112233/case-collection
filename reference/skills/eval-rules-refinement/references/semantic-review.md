## 定向复核及限制

更新后的入口需在以下决策上保持一致，而不是匹配案例 ID 或条目数量：

| 复核输入/错误反例 | 应能作出的决定 | 防止新增限制的对照 |
|---|---|---|
| 159整堆移动、抽非顶盘、通关后只归位但提示未复位 | 归属与合法性不重扣；补核心顶盘规则；核对真正的新局恢复 | 不指定左右目标、唯一路线、精确最少步数或视口纵向中心 |
| 115控件可见但动作无效；状态存在却跳播；某状态表示本身缺失 | 分别归动作、播放或表示事实；不把一个错误计两次 | 不要求预渲染全部 DOM 层，仍允许计算生成状态 |
| 115规则原文列举但无顺序要求；换一题明确要求按顺序 | 前者留待确认，后者检查顺序 | 不能普遍忽略顺序，也不能普遍强制列举顺序 |
| 190缺格使旗位派生受阻；另一情况棋盘完整但旗层错位 | 前者唯一归因，后者可独立失败 | 不能把所有同坐标错误都合并 |
| 190超过十旗、出现负数、≥10未终局按压 | 验证有据边界与😓，常态放宽不扩散到按压 | 不强制同时插满81旗，不指定未限定的释放后符号 |
| 一般 Region 多个自身外观属性；同对象的复合动画 | 仍可合为一条，属性作 Evidence | 不能因为本次拆分混合关系就机械拆颜色、尺寸、形变 |
