# Error 404 with pure CSS: Monument Valley inspiration

- Author: SusCasasola (CodePen).
- Public original: https://codepen.io/SusCasasola/pen/mLREVP
- Code license: MIT for public Pens, per https://blog.codepen.io/docs/pens/licensing/. Original concept credit: Monument Valley inspiration (as stated in the original title); the visible scene is generated from CSS and HTML rather than game artwork files.
- original.pug and original.sass are copies from the public author's CodePen editor. original.js is empty.
- compiled.html and compiled.css are CodePen's own output copied from the public editor's “View Compiled HTML” and “View Compiled CSS” controls. Leading/trailing whitespace is retained as copied. No changes made to the authored program or to these compiled files.
- Build-time imports: compass/reset and compass/css3 from Compass (https://compass-style.org/). Their mixins/reset are represented in the generated CSS.
- Runtime font stylesheet referenced in both Sass and compiled CSS: https://fonts.googleapis.com/css?family=Poppins
- The Sass compiler randomizes decorative star placement, size and blink duration. This captured compiled output pins the generated rules; runtime animation still changes star opacity. The stairway geometry is static.
- Render observation: CodePen editor preview loaded the hollow golden staircase diamond, figure, stars/planets, 404 label and button. No interaction required.
