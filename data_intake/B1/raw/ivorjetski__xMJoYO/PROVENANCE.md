# Pure CSS Still Life - Water and Lemons

- Author: Ben Evans, CodePen handle ivorjetski.
- Original: https://codepen.io/ivorjetski/pen/xMJoYO
- Public Pen source license: MIT per https://blog.codepen.io/docs/pens/licensing/.
- Original HTML and SCSS copied unchanged from the author's public editor. Original JS is comments only, including attribution links. Compiled CSS copied using the editor's View Compiled CSS command, not rebuilt. The Sass uses random() for rind texture; this captured CSS fixes those generated values.
- No external image or script needed for the drawing; original JS explicitly says no images. Original is rendered from CSS gradients, shadows, blend modes, transforms and clipping.
- Verified default image in the public CodePen editor preview, after CSS paints: elliptical drinking rim and waterline are separate; sharp reflective streaks travel down the glass and change at water level. A partly obscured whole lemon sits behind the glass with yellow detail drawn through the glass area; a cut half sits in front-right; dark reflections lie below the objects. Interpret as drawn optical cues, not a physical refraction simulation.
