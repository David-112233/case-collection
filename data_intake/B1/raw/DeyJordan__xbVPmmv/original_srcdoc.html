Press and drag to explore the 3D book

This CodePen is a demo showcasing a pure CSS 3D project (without libraries such as three.js) created for the website lalie-landry.com, a French fantasy author. Many thanks to her for allowing the publication of this CodePen.

I have textured the book and its silver-foiled parts using the files sent to the printer for a better visual effect. You can view the book without textures by clicking the checkbox at the top left of the page.

The original page is built with Vue.js and SCSS, which helps to keep the code a bit more readable.
