Proof of concept for client internal desk booking tool

SVG markup defines the walls etc for an office. Additionally, the <defs> describe required desk/chair objects to be drawn into the office.

A JSON object describes all desks for a particular office, together with the layout. Individual desk attributes allow a desk to be un-bookable, eg for Covid distancing.

JavaScript iterates through the JSON and appends desks to the SVG as required.

It must be noted that this is not an accessible interface, and rather functions to enhance the booking process.
