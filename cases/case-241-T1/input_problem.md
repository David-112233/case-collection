## 2. 写进 input 的取舍（选了最保守的做法，待用户确认）

- **图标：** 源码的 `<i class="far fa-building">` 本意可能是大楼图标，但作品没有引用 Font Awesome，实际只显示数字。GT 照来源保留，input 按实际显示写“编号写在圆圈正中、斜体数字”，不要求大楼图标。
- **写了两个像素尺寸：** 圆环约 200、实心圆约 130（以及文字块宽约 200），圆的大小比例是错落构图的一部分；如果用户希望不写像素，可改为“实心圆直径约为圆环的三分之二”。
- **小圆点只写组数、颜色和“散落、不重叠”**，以及最明显的一个大圆点的位置；其余小圆点的精确位置和大小不写，避免拆细条件。
- **颜色只写颜色名，**不写色值。
- **没写进 input：** 992px 以下改成一行横排、可横向滚动的响应式布局；页面高约 100vh 加上下外边距、下方文字块部分在首屏之外。前者是来源真实存在的行为，但评测是否检查窄视口未定，写进去会多出一组只在窄屏才能判定的条件；后者只是来源的边距结果，不是作品要表达的效果。
- **没写“没有动画、没有交互”：** 来源本来就没有，功能需求写了“静态信息图”，不另加禁令。

## 3. 档位

GT 与来源都没有任何动态，按难度模型 v2.1 为 T1，与入库暂定一致，未改名。另：入库评价提到“缺少强前后遮挡、交错关系”，这个作品的立体感只在圆环的凹面内阴影，空间难度偏低，是否保留由用户定。

## 4. 需要用户定的事

1. 是否要求 992px 以下的一行横排布局（第 2 节）。
2. 是否接受写像素尺寸。
