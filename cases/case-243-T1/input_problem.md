## 2. 写进 input 的取舍（选了最保守的做法，待用户确认）

- **静止画面选来源默认画面（绕竖轴 234°），**不选 `article` 原写的 `-30deg` 加平移（作者写了但从未显示）。input 用“纸巾盒工位离观者最近、在方柱右前方”描述朝向，没有写角度。
- **写了“画面静止”**（在功能需求里）。来源可选的旋转被去掉，不写的话模型照来源做成持续旋转也合规，但朝向类条件就无法判定。如果用户认为这属于从 GT 反推的新要求，可以删掉。
- **没写“Animate”复选框和旋转。** 若用户希望保留“勾选后场景持续旋转、取消后停住”这一交互，GT 要恢复复选框与动画，档位应回到 T3（见第 3 节）。
- **没写进 input：** 每个工位里的浅青色薄板（几乎全被抽屉柜挡住）；第三个工位电脑偏移的位置和显示器后仰角度；显示器与键盘的微小倾角；地面网纹的具体参数；所有尺寸和色值。
- **笔筒、铅笔、便签写进去了，**因为它们是区分四个工位的唯一细节；但太小，若用户认为难以判定可删。

## 3. 档位

来源的动态是“勾选复选框后整个场景持续旋转”。GT 去掉旋转后，复选框没有作用，一并删除；GT 无动态、无交互，已由 T3 改为 T1（目录名 `case-243-T1`）。

## 4. 需要用户定的事

1. 是否接受去掉复选框（第 2 节第三条），以及因此改为 T1。
2. 是否保留“画面静止”一句。
3. 笔筒、铅笔、便签这几个很小的细节是否保留。
