## 按 CSS 推算的几何

- 房间宽高等于视口，纵深 100rem；透视距离 100rem，房间整体后移 50rem，所以左右墙、天花板、地板从视口边缘（z=0）延伸到 z=-100rem，后墙在 z=-99rem，按透视缩放约为 0.5，应显示为视口正中、宽高约一半的矩形。
- 左墙由四块条带围出窗洞：上 13%、下 27%、前后各 25%，窗洞占纵深中段一半、高度 13% 至 73%；窗洞上沿和窗台各有 10rem 深的侧面，窗框后移 8rem 在墙外侧，由上、下、右三边和中间竖梃组成。

- 吊扇在天花板左右居中、纵深中点，整体缩放 0.7：吸顶圆盘、10rem 吊杆、三层金属圆盘电机、深色转子和三片 19rem 长的木棕色扇叶（20°、120°、240°，各前倾 15°）。
