## 渲染核对（2026-11-24，云端浏览器）

- **方法：** 用项目的云端浏览器经 raw.githack 打开提交 9a789c5 的 `ground_truth.html`（页面直接加载，未出现提示页），视口 1280×800 与 500×800；另在 1280 视口下放大扬声器与标志、控制条左中段、控制条右端与键盘右端三处（约 3 倍）。浏览器工具最小宽度为 500，375 视口无法实现。截图只用于查看，未入库；该浏览器无法执行脚本测量，所以没有精确包围盒。
- **结论：** 画面完整，无渲染错误；Montserrat 特粗体已显示在标志上；机身在 1280×800 下约位于 (160, 250)–(1120, 510)，与推算一致；17 白键、12 黑键，分组 2、2、3、2、3，每个黑键压在相邻两白键分缝上；500 宽时机身左对齐、横向溢出并出现横向滚动条。GT 不需要修改。
- **与 input 不符、已改的 3 处：** 扬声器的圆形喇叭只是隐约可见的暗色区域，竖向筋条只在圆内可见；tempo 标签在窄按钮组中段偏左；键床是比机身略深的浅灰褐色。详见 [../input_problem.md](../input_problem.md) 第 1 节。
