# case-247 input 的问题与取舍（2026-11-24，duet）

## 1. 外观已按渲染核对

GT 经 raw.githack.com 在云端浏览器打开，在 1280×800 和 500×800 截图，覆盖默认、夜间、缩放、夜间加缩放四种状态，并放大房间查看（见 [review_20261124/static_check.md](review_20261124/static_check.md)）。input 里的部件、位置、配色和两种切换的效果都与截图一致。

## 2. GT 的取舍（待用户确认）

1. **删掉显示器里的外站网页。** 来源两块屏幕用 `<iframe>` 嵌入 css-tricks.com 和 jhey.dev。前者拒绝被嵌入，只显示浏览器错误页；后者是作者个人站，内容实时变化（核对时页面里有实时天气、正在播放的歌曲）。这既不是准静态，也无法写进题目，所以删掉，屏幕显示为素灰色。缩放功能原本的看点是看清屏幕上的网页，删掉后缩放画面只剩书桌正面。**若用户想保留，恢复两行 `<iframe>` 即可，input 仍不描述屏幕内容。**
2. **删掉“椅子旋转”开关。** 打开后椅子无限自转，属于循环动画，不是可静止的状态，所以连按钮一起删除。
3. **删掉背景音乐和“声音”开关。** 自动播放、循环的音频，与画面无关。
4. **夜灯循环变色固定为粉色。** 来源夜间模式下小方块灯和两处光晕每 10 秒在粉、蓝、紫、绿之间循环，GT 固定为起止帧的粉色。input 写“粉色”。
5. **右下角按钮重新编号**，两个按钮紧挨着，不留被删按钮的空位。

## 3. 写进 input 的取舍

- **写了“切换瞬时完成”。** 过渡是统一由一个变量控制的 0.2 秒，GT 归零；与 case-228 不同，这里我写进了“瞬时”，因为来源的过渡本来就很短，写上可以避免模型加长缓动后影响判定。如果用户认为这是从 GT 反推的新要求，可以改成只写“切换后保持状态”。
- **写了“除点击切换外画面静止，没有循环动画，也没有声音”。** 对应 GT 删掉的旋转、变色和音乐，避免模型照来源加回去。同样是 GT 的设计结果，用户可以决定是否保留。
- **没写的：** 屏幕内容；各部件的具体尺寸和色值；窗外照片、桌面石纹、地毯的具体图片（只写颜色和质感）；椅背头像的具体图案（只写“小头像标志”）；夜间模式下绿植的显示（来源对三维元素加了亮度滤镜，夜间绿植会错位显示成上下两丛，是来源的渲染问题，input 不描述）。
- **“整体尺寸随视口较短的一边等比缩放”**：来源全部用 vmin，500×800 截图中房间等比缩小、完整可见。

## 4. 档位

GT 保留“点击切换并保持”的灯光和缩放两个开关，仍为 T3。
