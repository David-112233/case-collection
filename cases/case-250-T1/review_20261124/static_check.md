# case-250 GT 自检记录（2026-11-24）

## 不依赖浏览器的核验

- 差异见 [source_to_gt.diff](source_to_gt.diff)：只删 CodePen 样板。GT 没有脚本、动画和过渡。
- 版式要点（由 CSS 读出）：`body` 用 `column-reverse` 排列，所以 01 在最下、04 在最上；横幅宽 30em、高 10em；宽屏（`--wide: 1`）时奇数条向左、偶数条向右平移 15%，并绕 Y 轴转 ±0.1° 配合 `preserve-3d` 决定圆片与相邻横幅的前后；圆片直径 12.5em（6.5em 字号 × 1.923），上边距为负，所以向上超出横幅。

## 云端浏览器渲染核对

**方法：** 用项目的云端浏览器打开 `https://raw.githack.com/David-112233/case-collection/e4e1adf/cases/case-250-T1/ground_truth.html`（gt_ready 提交，直接进入页面，没有提示页），视口 1280×900、600×900、500×900，截整页查看；另打开同一提交的 `source.html` 对照。工具最小宽度 500，480px 以下的版式用本目录的 `frame_view.html?w=450` 把 GT 放进 450px 宽的同源 iframe 查看（结果见下表 450 宽一行）。截图只在核对时查看，没有入库。

**结论：GT 与来源渲染一致，宽屏和中等宽度版式与 CSS 推算一致，GT 不需要修改。**

| 核对项 | 结果 |
|---|---|
| 1280 宽 | 四条横幅自下而上 01–04，左右交错（01、03 偏左，02、04 偏右）；圆片直径约 200px，向上压住上一条横幅的一角，并向外超出横幅端部；横幅为两端深、中间浅的横向渐变；横幅下方有偏向外侧的模糊投影；圆片米白渐变、细描边、带侧向阴影；编号与横幅同色 |
| 600、500 宽 | 不再交错、左右对齐，横幅宽 480px 不变，间距加大，圆片落在横幅宽度以内、只向上超出约 40px，不再压到上方横幅 |
| 450 宽（`frame_view.html?w=450`，提交 ed574f7） | 横幅占满宽度、直角，相邻之间窄缝；圆片消失，编号为白色大号数字在左上，下面是带图标的标题和说明文字，文字完整；横幅下仍有模糊投影 |
| 来源自带的渲染瑕疵 | 600、500 宽时，02、04 两条横幅（圆片在左）的标题图标和说明文字的最左几个字母被一条竖线切掉（如 “Cake” 显示为 “ake”）。source.html 在同宽下完全一样，是来源 3D 层叠造成的，与 GT 改动无关，GT 未修。1280 宽时文字完整 |
| emoji 图标 | 灰色显示；字形取决于浏览器的 emoji 字体，不同截图之间 ⭐、✔️ 的字形还出现过不同，input 只按字符给出 |
| 字体 | 来源字体栈为 Trebuchet MS、Verdana、无衬线；云端浏览器两者都没有，显示为默认无衬线体 |
| 局部放大截图 | 本页是 3D 层叠，局部放大截图有时漏画圆片，以整屏截图为准 |
