# case-248 input 的问题与取舍（2026-11-24，duet）

## 1. 写进 input 的取舍

- **给出图片地址和替代文字：** 与同作者的样板 case-227 一致。图片能否在评测环境加载属于资源问题，按输出契约 v2 记 UNRESOLVED。
- **没写具体数值：** 背景色值、纸宽 300px、内容区 650px、7% 白边、滤镜的 70% 饱和度和 85% 对比度、各渐变角度都不写，只写相对关系（“比原图略宽略高”“饱和度和对比度明显降低”“三分之一和三分之二处”）。折痕位置写成等分是因为它决定“两列三行六块”的折法，属于结果。
- **折面明暗只写“轻微、部分折面靠近纸边或折痕一侧略暗”：** 来源用十组不同角度的渐变给六块折面加暗角，每块都不一样，写细了就是把 GT 的实现拆成条件，所以只写总体效果。
- **“页面面向桌面宽屏”：** 来源内容区固定 650px 宽，500 宽时右列被截、出现横向滚动条。input 不对窄屏提要求，写法与 case-227、229 一致。
- **没写“页面静止、没有动画”：** 来源本来就没有动态，与 case-229、235 一样不加这句。

## 2. 需要用户留意的地方

1. **选题顾虑：** 作品是一个 CSS 纸面效果（折痕、暗角、投影）套用在三张图片上，结构简单，难点集中在“折痕的亮暗细线”“折面暗角”“下沿阴影带”这几处微妙的光影，评测时这些细节的判定可能比较主观。它已在追加审核中被选中，我照常加工，提请用户留意。
2. **原图与折叠海报对照：** 来源左列原图就是“修改前”的参照，我把它当作作品的一部分写进了 input（三组、左原图右折叠）。如果用户只想考折叠海报本身，可以去掉左列，但那需要改 GT，我没有改。
