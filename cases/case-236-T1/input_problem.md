# case-236 input 的问题与取舍（2026-11-24，duet）

## 1. 外观依据

`input.json` 依据 GT 源码和云端浏览器截图（1280×800、500×800，见 [review_20261124/static_check.md](review_20261124/static_check.md)）写出。颜色只写颜色名，没写色值和尺寸，与 case-224、227 样板一致。

## 2. 写进 input 的取舍（选了最保守的做法）

- **没写进 input：** 被删掉的交互（拖动旋转、右键平移、滚轮缩放）；主机背面的散热格栅（在远侧长侧面上，默认视角看不到）；手柄弧形边角在渲染器里的面片穿插；各部件的具体尺寸、色值；实现手段。
- **写进了 input：**
  - “页面完全静止，没有动画，也没有悬停、点击、拖动等交互效果”，与 case-230、234 的写法相同。
  - 左右手柄按键布局按 GT 写到“菱形、摇杆在哪一侧、单独小按键在哪”，这是作品辨识度最高的部分；没写哪个按键对应真机的 ABXY 或 Home。
  - “两个手柄远侧外角各有一块黑色肩键”。右侧肩键在截图里清楚可见；左侧肩键在左摇杆后方只露出一部分，评测时可能不易判定。
  - 地面投影写成两部分（紧贴机身的深色接触阴影、向远侧和右侧伸出的较浅投影），按键的淡影只写“方向与地面投影一致”，没写具体角度。
- **“整体尺寸随视口较短的一边等比缩放”**：来源全部用 vmin，写成可判定的结果；窄视口下模型几乎占满宽度，没写边距要求。

## 3. 需要用户定的事

1. 档位：来源唯一的动态是拖动、平移、缩放视角，按 3D 场景统一做法删去后为 T1（已 retier）。如果希望保留“拖动旋转视角”，属于复杂交互，按规则不宜放进 GT。
2. 左侧肩键是否保留在 input 里（见上）。
