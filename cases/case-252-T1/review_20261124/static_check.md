# case-252 GT 自检记录（2026-11-24）

## 代码层面的核对

- GT 与 `source.html` 的差别只在 `<head>` 的 CodePen 样板和 `<body translate="no">`（见 [source_to_gt.diff](source_to_gt.diff)），`<style>` 与 `<body>` 内容逐字相同。
- 无内联脚本、无 `@keyframes`、无 `transition`、无 `:hover` 等伪类；唯一的外部脚本是 prefixfree（只补 CSS 前缀）。GT 无需去动画，也没有交互可测。
- 版式由自定义属性切换：`--wide` 未定义时（视口宽于 775px）为宽屏版式；775px 及以下 `--wide: 0`，`content: var(--wide, "")` 与 `clip-path: var(--wide, …)` 变为无效值，斜切标签消失、圆角裁切取消，为窄屏版式。

## 渲染核对（云端浏览器）

方法：用项目的云端浏览器经 raw.githack 打开提交 `1c969df` 的 `ground_truth.html`，视口 1280×800 和 500×800 各截图一次，并放大局部查看。浏览器工具最小宽度为 500，做不了 375。截图只用于查看，未入库。本地可运行 [shot_gt.py](shot_gt.py) 补 375 宽和测量数据。

结论：

- **1280 宽（宽屏版式）**：浅灰背景上，四条横幅自上而下排成一列，水平居中，宽约 768px，彼此间隔约 24px，每条下方有柔和投影。每条横幅为两端全圆的胶囊形，白到浅灰渐变的外框里嵌着一圈约 3px 的彩色细线，细线内为上灰下白渐变的底板，右端圆角。左端是一个灰色圆环包着的彩色圆标，圆标上半亮、下沿有一条较暗的弧带，中间是白色两位编号 01、02、03、04。圆标右侧有一块白到浅灰渐变的斜切标签，从横幅顶边一直到底边，右缘自左上向右下倾斜，压在彩色细线和底板的左段之上（彩色细线在标签处被盖住）。标题为黑色粗体小写，位于标签斜边右侧、横幅上半；其下一行为常规字重的说明文字。四条的配色依次为橙红、青绿、深棕、草绿，彩色细线与圆标都从上方的浅色过渡到下方的深色。
- **500 宽（窄屏版式）**：四条横幅变为占满视口宽度的直角矩形卡片，没有斜切标签，也没有圆环；彩色细线成为直角边框；彩色圆标缩小到约与标题行同高，位于标题左侧；说明文字在标题下一行，从卡片左缘开始。配色和编号不变。
- **字体**：云端浏览器里显示为常规无衬线体（来源指定 Trebuchet MS、回退 Verdana，本环境没有这两种字体）。
- **静止**：无任何动态；外部脚本 prefixfree 加载正常，未见渲染问题。GT 无需修改。
