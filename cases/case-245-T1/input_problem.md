# case-245 input 的问题与取舍（2026-11-24，duet）

## 1. 外观已按渲染核对

GT 经 raw.githack.com 在云端浏览器打开，在 1280×800、1280×992、500×800 截图，并放大 2–4 倍查看花样（见 [review_20261124/static_check.md](review_20261124/static_check.md)）。三种面的配色、两种顶面、四类花样、每排约 14 格、纵向约三组、矩形四周的深色边和裁切方式，都与截图一致。

## 2. 这道题最大的问题：花样无法逐格写清

来源是 13 排、每排 21–22 个空心立方体，按 `:nth-child(4n…)` 和 `:nth-child(6n…)` 组合出 4 排 × 6 格的重复单元，单元里有十几种不同的格子（不同的面、偏移和伪元素）。用文字逐格描述既不现实，也不可能让模型按文字复原同一张图。

**默认做法：** input 只写到“花样类别”这一层：三个面的配色、两种顶面、四类变化（小立方体、窗洞、台阶口、横跨的红色台面）、它们组成固定组合并规则重复。每一项都能从截图判定，但模型可以用完全不同的排布满足 input，评分时只能看类别和整体观感，抓不住来源最精彩的“桥面穿插、空间错觉”。

**请用户定：** 这种粒度能否接受；如果不能，这个案例可能属于“来源无法改成可评测题目”的情况，建议考虑撤下。

## 3. 写进 input 的取舍

- **写了“宽高比约 4:3、固定像素大小、视口小时四边裁掉、不出现滚动条”**：来源画框为 1176×864 内容加 120px 同色边框，容器 `overflow: hidden`。在常见的 1280×800 视口里矩形上下两边会被裁掉，这是来源原样，GT 未修。
- **写了“每排约 14 格”“纵向约三组”**：由 1176 ÷ 84 和 864 ÷ 288 得出，并已在截图中数过，用来约束格子大小和重复规律，比写像素数值更接近样板的写法。
- **没写的：** 具体色值、像素尺寸；条纹的 1px 间隔（只写“极细”）；部分格子之间露出背景色的细小缝隙（来源的副产品）；作者注释里的视频链接。
- **业务背景里的“既像实心方块又像房间内角”** 只作为题意说明，不放进布局约束，因为它是主观观感，无法判定。

## 4. GT 删除 YouTube 推广徽标（待用户确认）

来源右下角有一个红色 YouTube 徽标，链接到作者的教程视频，悬停时放大并弹出文案卡片。它与作品画面无关，按“与评分无关就删掉”删除，档位因此由 T2 改为 T1。若用户认为应保留，GT 恢复徽标（悬停过渡改为瞬时），档位改回 T2，input 需加一条徽标的描述。
