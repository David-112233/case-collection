## 关于 `/style.css` 与 `/script.js`（推断，未核验）

这两个引用位于作者粘贴进 HTML 面板的一整份文档里（`<body>` 里又嵌了一层 `<!DOCTYPE html><html><head>…<body>`），看上去是作者本地文件的写法：

- 所有样式都已作为 CodePen 的 CSS 面板内联在 `<style>` 里，画面不依赖 `/style.css`。
- CodePen 的整页输出会把 JS 面板的代码以内联 `<script>` 放在 `</body>` 前；`original_srcdoc.html` 里除了 CodePen 的 console 垫片之外没有任何内联脚本，说明这件作品的 JS 面板很可能是空的。
- 作品标题是 “Polaroid Camera In CSS”，作者注释里的教程链接也指向一篇纯 CSS 教程。

据此推断 `/script.js` 在 CodePen 上也不存在，删掉它不会丢掉原作的交互。**这只是推断**：没有去 CodePen 或其他地方抓取脚本内容核实。
