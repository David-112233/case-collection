# case-238 input 的问题与取舍（2026-11-24，duet）

## 1. 外观依据

`input.json` 依据 GT 源码和云端浏览器截图（1280×800、500×800，见 [review_20261124/static_check.md](review_20261124/static_check.md)）写出。颜色只写黑、白、灰的深浅，没写色值和尺寸。

## 2. 写进 input 的取舍

- **页面面向桌面宽屏：** 来源两个部件固定宽度，窄屏下会横向滚动、歌单卡被挤到视口外，所以只按桌面宽屏写，与 case-227 的写法相同，没写窄屏表现。
- **文字照抄：** 标题、“Side A”“Side B”、两栏里的文字都按 GT 原文写入（包括作者的玩笑句 “I'm not good at lorem ipsum”），这是作品的固定内容。
- **手写体只写风格**（“圆润随意的手写体”），没写字体名；如果希望指定 Gochi Hand，可以加进 functional_requirements。
- **没写进 input：** 横线的行距、条纹的具体条数、卷轴孔的具体尺寸、作者注释“Created originally for sava.io”、HTML 末尾多余的闭合标签。
- 写了“页面完全静止，没有动画，也没有悬停、点击等交互效果”，与 case-230、234 的写法相同。

## 3. 需要用户定的事

1. 入库时备注“整体为正视平面构图，空间深度弱，不为凑数优先推荐”。GT 与来源相同，是一张平面线稿，难点主要在磁带的层叠细节和横线纸对齐。是否仍收。
2. 是否在 input 里点名手写字体。
