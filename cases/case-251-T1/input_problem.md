# case-251 input 的问题与取舍（2026-11-24，duet）

## 1. 写进 input 的取舍

- **作品看点：** 宽屏下色块的斜切加折角（“彩色折纸条、交替折角”）和左右交替，以及断点后整体改成顶部横条。input 写了宽屏和窄屏两套版式，因为来源标题就是 Responsive infographic。
- **折角的写法：** 来源用两个反向斜切的伪元素叠出折角，input 只写结果：斜边、斜边下半段的深色三角形、整体呈“<”“>”的轮廓、折角带阴影。“<”“>”是为了让方向可判定。
- **写了字体 KoHo 和背景图地址：** 两者都是 GT 实际加载并可见的外部资源（输出契约 v2 允许），与 case-227 给图片地址的做法一致。资源加载失败按 UNRESOLVED 处理。
- **断点写成“约 624px”：** 来源断点是 39em，按 16px 根字号约 624px，与卡片最大宽度相同，所以写成像素便于判定。
- **“卡片宽度固定（约 620px）”：** 写了近似值，因为宽屏下卡片是否接近这个宽度决定了胶囊比例；如果用户认为写数值太细，可以改成“宽度固定、不随视口变宽”。
- **没写的：** 具体色值与 HSL、斜切角度 27°、圆点透明度 0.8–0.2 的级差（只写“逐渐变淡”）、卡片投影数值、15em 以下字号缩小的断点。

## 2. 需要用户留意的地方

1. **与 case-250 同一作者、同类题材：** 两题都是“四条带编号的信息图横幅、宽窄屏两套版式”，甜点名和说明文字也相近。考法不同（250 考圆片叠盖，251 考斜切折角），但题库里可能显得重复，请用户留意。
2. **选题顾虑：** 本作接近单组件演示（四张同款卡片），难点在折角的几何与渐变方向。已在追加审核中被选中，我照常加工。
