# case-239 input 的问题与取舍（2026-11-24，duet）

## 1. 外观依据

默认状态依据 GT 源码和云端浏览器截图写出（见 [review_20261124/static_check.md](review_20261124/static_check.md)）。**悬停效果没能在云端浏览器里触发**，“竖直抬起、投影变淡并模糊扩散”是按源码推算的，待本地截图核对。

## 2. 写进 input 的取舍（选了最保守的做法）

- **没写进 input：** 被去掉的卷轴旋转动画；悬停时的 0.6 秒过渡（GT 去掉了过渡时长，input 只写结果，不限制有无过渡）；手形光标；具体尺寸、色值、字体名；注释里的两张纹理图片。
- **写进了 input：**
  - “除此之外画面是静止的，卷轴不转动”，与 case-228、231 的写法相同；如果用户认为这一句属于从 GT 反推的新要求，可以删掉。
  - 卷轴颜色写成“透过窗口看到的卷轴为暗黄色”。源码卷轴底色是亮黄色，但正面是半透明深色、窗口处透出来后显得发暗，截图里是暗黄色；按看到的结果写。
  - 卷轴“侧面有一圈齿纹”：截图里能看到卷轴边缘一圈黑黄相间的短条，是卷轴侧面的面片。很小，评测时可能不易判定。
- **“磁头区两孔之间有一颗小螺丝”**：源码第 5 颗螺丝位于磁头区中部，截图可见，写入。

## 3. 档位

GT 保留的唯一动态是“悬停磁带时磁带抬起、投影变淡变虚，移开即还原”。它会改到投影这个独立元素，但不是显隐、展开这类结构性变化，属于难度模型 v2.1 例子里“卡片 hover 上浮 + 阴影加深”的情形，按 T2 判定，与入库暂定一致，不改名。如果用户认为“悬停驱动另一个元素（投影）”应算 T3，需要 retier。

## 4. 需要用户定的事

1. 档位按 T2 是否认可（见第 3 节）。
2. 是否保留“卷轴不转动”这一句。
